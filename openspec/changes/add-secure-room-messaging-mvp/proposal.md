# Proposal

## Why

Для первого работающего этапа нужны Android-клиент и сервис на двух узлах OpenMANET, через которые администратор выдаёт доступ, а пользователи общаются в закрытых комнатах текстом и вложениями. Сейчас проект содержит только согласованные требования; реализации нет.

## What Changes

- Добавить установку сервиса приложения на каждый тестовый Raspberry Pi 4B с OpenMANET 1.8 и Android-клиент без зависимости от Google-сервисов.
- Добавить выдачу администратором учётной записи для одного телефона через QR-код и открытие приложения по PIN; саморегистрации нет.
- Добавить закрытые комнаты, членство и проверку прав на узле при каждом чтении или изменении данных. Командир имеет доступ ко всем комнатам.
- Добавить текстовые сообщения и вложения до 100 МБ с трёхдневным сроком хранения, статусами доставки и загрузкой вложений на телефон по запросу.
- Обеспечить обмен между телефонами, подключёнными к разным из двух связанных узлов.
- Подготовить проверяемый APK и пакет сервиса для тестового стенда: два узла, 906 МГц, ширина канала 4 МГц.

В этот change не входят работа при разрыве и последующее слияние частей сети, BLOS, голос и видео: это отдельные пункты согласованного плана.

## Capabilities

### New Capabilities

- `device-provisioning`: административная выдача учётной записи, привязка одного телефона и PIN.
- `room-access`: закрытые комнаты, роли и проверки доступа.
- `room-messaging`: отправка, чтение и статусы текстовых сообщений.
- `room-attachments`: загрузка, выдача по запросу, проверка прав и срок хранения вложений.
- `two-node-delivery`: обмен сообщениями и вложениями между двумя связанными узлами.

### Modified Capabilities

Нет.

## Impact

- Новые компоненты: Android-клиент, сервис для Raspberry Pi/OpenWrt и обмен между сервисами двух узлов.
- Источник требований: `docs/requirements.md`; размещение сервиса: `docs/adr/0001-services-on-mesh-nodes.md`.
- Понадобятся отдельный накопитель на узле, подпись APK и проверка на двух имеющихся узлах. Выбор конкретных библиотек и минимальной версии Android выполняется в рамках технического проектирования без расширения согласованного функционального объёма.
