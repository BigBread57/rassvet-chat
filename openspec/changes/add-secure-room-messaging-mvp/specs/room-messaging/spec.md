# Spec Delta

## Purpose

Обеспечивает текстовую переписку внутри разрешённых комнат с понятным состоянием доставки и трёхдневным сроком хранения.

## ADDED Requirements

### Requirement: Отправка и чтение текста
Авторизованный участник с правом отправки SHALL иметь возможность отправить текст в комнату; участник с правом чтения SHALL видеть историю неистёкших сообщений этой комнаты.

#### Scenario: Обмен на связанных узлах
- **WHEN** участник отправляет сообщение из комнаты через один узел, а другой участник этой комнаты подключён ко второму связанному узлу
- **THEN** оба участника видят одно и то же сообщение с тем же идентификатором

### Requirement: Состояния сообщения
Отправитель SHALL видеть состояния «сохранено», «доставлено» и «прочитано» на основании подтверждённых событий, а не факта отправки запроса.

#### Scenario: Сообщение ещё не доставлено
- **WHEN** сервис сохранил сообщение, но не получил подтверждение доставки адресату
- **THEN** отправитель видит «сохранено», а не «доставлено»

### Requirement: Неизменяемая история
Обычный пользователь SHALL NOT редактировать или удалять отдельное отправленное сообщение.

#### Scenario: Попытка редактирования
- **WHEN** клиент запрашивает изменение ранее отправленного текста
- **THEN** сервис отклоняет изменение и сохраняет исходный текст

### Requirement: Срок хранения текста
Система SHALL удалять сообщение с узлов и телефонов через заданный срок после отправки; начальное значение срока составляет 3 дня.

#### Scenario: Истечение срока
- **WHEN** срок хранения сообщения истёк
- **THEN** сообщение больше не отображается и не выдаётся через API
