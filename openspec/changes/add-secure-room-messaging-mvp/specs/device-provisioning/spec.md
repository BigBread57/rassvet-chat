# Spec Delta

## Purpose

Обеспечивает выдачу доступа только администратором и привязку одной учётной записи к одному Android-телефону без зависимости от Google-сервисов.

## ADDED Requirements

### Requirement: Административная выдача учётной записи
Система SHALL разрешать создание пользователя и назначение его роли только авторизованному администратору; саморегистрация SHALL быть недоступна.

#### Scenario: Пользователь пытается зарегистрироваться сам
- **WHEN** неавторизованный клиент запрашивает создание учётной записи
- **THEN** сервис отклоняет запрос и не создаёт пользователя

### Requirement: Привязка одного телефона
Система SHALL активировать учётную запись на одном телефоне по выданному администратором QR-коду и SHALL отклонять повторную активацию этой учётной записи на другом телефоне.

#### Scenario: Первая активация
- **WHEN** пользователь сканирует действительный выданный QR-код на ещё не привязанном телефоне
- **THEN** телефон получает доступ к своей учётной записи, а код больше не может быть использован

#### Scenario: Попытка подключить второй телефон
- **WHEN** та же учётная запись уже привязана и другой телефон пытается её активировать
- **THEN** сервис отклоняет активацию без изменения действующей привязки

### Requirement: Локальная разблокировка PIN
Android-клиент SHALL требовать PIN для доступа к данным и ключам учётной записи после блокировки приложения, включая отсутствие интернета.

#### Scenario: Неверный PIN
- **WHEN** пользователь вводит неверный PIN
- **THEN** приложение не раскрывает историю и не начинает авторизованную сессию

### Requirement: Защищённое соединение
Клиент и сервис SHALL обмениваться учётными данными и содержимым только по проверенному шифрованному соединению; сервис SHALL отклонять устройство без действующей привязки.

#### Scenario: Подмена узла
- **WHEN** клиент подключается к узлу, подлинность которого не подтверждена при выдаче доступа
- **THEN** клиент не отправляет ему учётные данные и содержимое комнат
