# Spec Delta

## Purpose

Обеспечивает обмен между Android-телефонами на двух связанных узлах OpenMANET без зависимости от постоянно работающего центрального сервера.

## ADDED Requirements

### Requirement: Сервис на каждом узле
Каждый из двух тестовых узлов SHALL принимать авторизованных локальных клиентов и обслуживать комнаты без обращения к отдельному серверу на пункте управления.

#### Scenario: Клиенты на разных узлах
- **WHEN** два телефона подключены к разным узлам одной связанной MANET и состоят в одной комнате
- **THEN** каждый телефон может получить новые сообщения этой комнаты через свой узел

### Requirement: Передача состояния между связанными узлами
При действующем соединении узлы SHALL обмениваться актуальными учётными данными, правами, сообщениями и вложениями, необходимыми для работы комнат; повторная доставка SHALL NOT создавать дубликаты.

#### Scenario: Повторная передача сообщения
- **WHEN** узел повторно получает уже сохранённое сообщение с тем же идентификатором
- **THEN** в истории остаётся одна запись сообщения

### Requirement: Защита обмена между узлами
Узлы SHALL принимать служебные данные и содержимое комнат только от доверенных узлов по проверенному шифрованному соединению.

#### Scenario: Неизвестный узел
- **WHEN** неизвестный узел пытается передать состояние комнат
- **THEN** сервис отклоняет передачу и не изменяет локальное состояние
