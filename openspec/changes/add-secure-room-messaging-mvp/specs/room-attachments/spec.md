# Spec Delta

## Purpose

Обеспечивает безопасную передачу фотографий, видеофайлов и других вложений в комнатах без автоматической загрузки крупных файлов на телефоны.

## ADDED Requirements

### Requirement: Передача вложений
Участник с правом добавления SHALL иметь возможность приложить файл разрешённого размера; начальный предел составляет 100 МБ и SHALL настраиваться администратором.

#### Scenario: Превышение предела
- **WHEN** пользователь отправляет файл больше действующего предела
- **THEN** сервис отклоняет файл и не публикует частичное вложение в комнате

### Requirement: Целостность и права на получение
Сервис SHALL выдавать вложение только пользователю с правом чтения комнаты и SHALL удостоверяться, что сохранённый файл соответствует принятому содержимому.

#### Scenario: Прямая ссылка из другой комнаты
- **WHEN** пользователь без доступа к комнате запрашивает вложение по известному идентификатору
- **THEN** сервис отклоняет выдачу файла

### Requirement: Загрузка по запросу
Android-клиент SHALL автоматически получать сообщение о вложении, но SHALL загружать содержимое файла на телефон только после действия пользователя.

#### Scenario: Вложение не открывали
- **WHEN** в комнате появляется вложение и пользователь не открывает его
- **THEN** клиент показывает сведения о файле без загрузки его содержимого

### Requirement: Право сохранения
Клиент SHALL предлагать сохранение или пересылку файла в другое приложение только при наличии отдельного права комнаты.

#### Scenario: Сохранение запрещено
- **WHEN** пользователь без права сохранения открывает файл
- **THEN** приложение не предоставляет команду сохранения или пересылки

### Requirement: Срок хранения вложений
Система SHALL удалять содержимое и метаданные вложения с узлов и телефонов через заданный срок после отправки; начальное значение срока составляет 3 дня.

#### Scenario: Истечение срока вложения
- **WHEN** срок хранения вложения истёк
- **THEN** файл больше не выдаётся через API и удаляется из управляемого хранилища
