# ADR 0001: сервис приложения на узлах MANET

Статус: принято заказчиком.

## Контекст

Сообщения, голос и видео должны работать внутри отделившейся части MANET, включая случай отказа сервера на пункте управления. После восстановления связи сообщения и файлы должны синхронизироваться.

## Решение

Разрешено устанавливать и обновлять отдельный сервис приложения на каждом из планируемых узлов Raspberry Pi 4B. Система не должна зависеть от доступности одного сервера на пункте управления.

## Следствия

- Требуются локальное хранение и последующая синхронизация данных между отделявшимися частями сети.
- Данные хранятся в двух копиях, когда в связанной части доступны два узла. Сообщения и вложения удаляются через 3 дня; ожидается до 1 ГБ вложений в сутки на всю сеть.
- Размещение голосовых и видеокомпонентов, протокол синхронизации, размер накопителя и достижимая нагрузка пока не определены; их нельзя считать подтверждёнными этим решением.
